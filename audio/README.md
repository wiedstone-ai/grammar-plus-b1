# Direktori File Audio (Listening Exercises) - Grammar Plus B1

Folder ini digunakan untuk menyimpan berkas audio rekaman (format MP3, WAV, atau OGG) untuk soal-soal *listening* pada aplikasi **Grammar Plus B1**.

## Daftar Berkas Audio Latihan

| Nama Berkas | Label di Buku | Lokasi Latihan di Aplikasi | Keterangan Percakapan / Materi |
| :--- | :--- | :--- | :--- |
| **`tr2.mp3`** | **TR 2** | **Unit 1, Latihan 4** | Percakapan antara Juan & Kathy (*"Excuse me. Is this seat taken?..."*) |
| **`tr3.mp3`** | **TR 3** | **Unit 2, Latihan 2** | Kalimat-kalimat *a/an* (*"I always eat an apple after breakfast..."*) |
| **`tr4.mp3`** | **TR 4** | **Unit 2, Latihan 7** | Kalimat tunjuk *this/that/these/those* |
| **`tr5.mp3`** | **TR 5** | **Unit 2, Latihan 8** | Pertanyaan lisan & respon singkat |
| **`tr6.mp3`** | **TR 6** | **Unit 3, Latihan 2** | Kalimat artikel tertentu (*the*) |

---

## Cara Menambahkan / Mengganti Audio

1. Simpan file MP3 hasil rekaman / Text-to-Speech langsung ke folder ini:
   - Contoh untuk percakapan Juan & Kathy: Simpan dengan nama `tr2.mp3` di dalam folder `audio/`.
2. Aplikasi akan otomatis mendeteksi dan memutar berkas `audio/tr2.mp3` pada pemutar audio HTML5 bawaan di atas soal latihan.
3. Selain file lokal, Anda juga dapat menggunakan link audio online (misal URL Google Drive / hosting langsung) dengan mengisikan properti `audioUrl` di database latihan `js/data_units.js`.
